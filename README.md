# HelixCare Pulse

**Live demo:** [helixcare-pulse.vercel.app](https://helixcare-pulse.vercel.app)  
**Source:** [github.com/TargiX/helixcare-pulse](https://github.com/TargiX/helixcare-pulse)

Astro marketing rebuild sample for a premium healthcare AI site. The project focuses on responsive page composition, reusable content sections, performance-friendly static output, and a polished B2B visual system.

## Stack

- Astro
- TypeScript
- CSS modules/global CSS
- Vercel deployment

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
